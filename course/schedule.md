# PHI 215 Symbolic Logic — Fall 2026 Schedule

This course is asynchronous and remote. Each week corresponds to a course module containing the assigned readings, lectures, and exercises for that portion of the course.

All homework assignments and exams are available through Microsoft Forms throughout the semester. Students may submit them whenever they are prepared to do so. The assessments listed below indicate the **recommended point in the course sequence** at which each assessment should be completed.
