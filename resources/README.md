# Shared Readings and Video Lectures

These resources are used by both the PHI 215 course and the Logic Competency Exam preparation pathway.

## Readings

### Primary Text

Gary Hardegree, *Symbolic Logic: A First Course*.

The text is available through Hardegree's University of Massachusetts course page:

https://courses.umass.edu/phil110-gmh/MAIN/IHome-5.htm

### Secondary Text

John G. Bennett, *Introductory Logic*.

A copy is available online here:

https://www.scribd.com/document/82264191/John-Bennett-Intro-Logic-Book

Hardegree is used extensively for symbolization and proof theory. Bennett is particularly useful for semantic interpretations and portions of first-order logic.
